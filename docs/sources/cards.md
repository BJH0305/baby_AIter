# 근거 카드 제출함 (한서희 작성 → Claude가 js/knowledge.js로 옮김)

> 코드 파일(js/knowledge.js)을 직접 고치지 말고 **여기에** 아래 양식으로 추가한다. 문법이 틀리면 앱이 멈추기 때문.
> 링크를 직접 열어 확인한 카드만 `확인: 완료`로 쓴다. 원문 파일(PDF 등)은 올리지 말고 링크만.

## 양식 (복사해서 아래에 추가) — 10/30 범위 변경: "원인 후보" 카드
```
### 카드: (원인 분류 이름, 예: 좌절·표현 부족)
- 연령: 00~00개월
- 이 원인일 때 흔한 상황 (관찰 단서 2~4개):
  1.
  2.
- 원인 설명 (부모용 한두 문장):
- 관찰 질문 (공식 자료에 있는 관찰 항목 기반, 예/아니오로 답할 수 있게 1~3개):
  1.
- 대응 한 줄:
- 전문가 상담 신호 (없으면 "없음"):
- 위험 신호 단어 (입력에서 찾을 단어, 예: 상처, 피가):
- 출처: 기관명 - 자료 제목 - URL
- 근거 문장 (페이지에 실제로 있는 문장 그대로, 40자 이내):
- 확인: 완료 / 미완료
```
