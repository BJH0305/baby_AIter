## 동작 구조
```
질문 검사(7문항 + 선택 메모, 24~47개월)
  → 규칙 기반 후보 정렬 (js/ai.js scoreCauses, 내부 가중치)
  → 위험 답변·위험 단어를 먼저 확인 (해당 시 AI 생략)
  → AI는 선택 답변과 상위 후보 카드의 설명만 재작성
  → 후보·선택 답변·한 줄 대응·원문 인용·쪽수 표시
  → 연결 실패·형식 불일치 시 규칙 설명 유지
  → 한 탭 피드백과 검사 기록 타임라인
```

## 팀 결정 후속 반영
- 화면 연령을 개월 수로 통일하고 피드백 1탭을 유지했습니다.
- 원인별 대응을 `tips: [{text, page, evidence}]` 배열로 전환했습니다. 같은 근거 PDF의 해당 쪽 주변에서 확인한 내용만 2~3개씩 목록으로 보여 줍니다.
- 카드 원문 검수 상태는 미완료이며 원문 PDF는 로컬에만 보존합니다.

- 후속 Pages 검증 완료: 개월 수 표시·대응 목록과 줄별 쪽수·375px 가로 넘침 없음·콘솔 오류 0.

- F0 완료: 원인 7개 팀원 검수 완료 반영 — verified true 7개, 카드 확인 완료 7개; 발행기관 미확인 유지

- F1 완료: 100dvh 앱과 내부 스크롤·항상 하단 탭바 — flex 화면·content 스크롤 적용; 375px와 데스크톱은 최종 배포 검증

- F2 완료: 첫 안전 문항 분리·컨디션 질문 수정 — 총 8문항. 아픈 곳은 CHLA PDF 1쪽 관찰 항목으로 condition 3점. 대상·장소는 원인별 직접 연결 근거 부족으로 무점수, AI 참고만 유지. 이전 injury 기록 안전 처리 유지

- F3 완료: 전 문항 기타 직접 입력·공백 진행 차단·AI 전달 — 기타 무점수. Worker 7항목 한도 때문에 안전·컨디션을 한 항목에 묶어 8개 답변 원문 전달(직접 입력 40자). Worker 변경 없음

- F4 완료: 홈·기록 삭제와 전체 기록 초기화 확인 시트 — 취소·삭제 바텀시트, 프로필 보존, 제목 5회 시연 복원 유지, 삭제 후 빈 결과 처리

- F5 완료: 12~59개월 검사 허용·주 대상 외 참고 안내 — 안전 안내 뒤 결과 상단에 참고용 문구, 원인 카드의 주 대상 연령 데이터는 유지
