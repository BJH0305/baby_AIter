# 베이비 AI터 — 구현 지시문 (순서대로 복사-붙여넣기)

> 사용하는 사람: 배준희. Codex에게 지시하는 사람은 한 명뿐이다 (`docs/TEAM.md`).
> Codex는 `swdna-starter` 폴더를 작업 폴더로 열어서 쓴다. Codex는 `AGENTS.md`를 자동으로 읽는다.
> 진행 방식: **Codex에게 지시 → 화면 확인 → Claude에게 "검토해" → 다음 단계.**
> **자동 진행**: Codex에게 `docs/RUN.md 읽고 진행해` 한 줄이면 허락이 필요한 지점까지 알아서 진행한다. 아래 단계별 지시문은 수동으로 끊어서 할 때 쓴다.
> 작업 목록 원본은 `docs/TASKS.md`, 검토 결과는 `docs/REVIEW.md`. 이 파일은 "언제 무엇을 말할지"만 정리한 것이다.
