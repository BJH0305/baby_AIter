# 진행 기록 (꾸럼e 옮겨 적기용)

> 수행 점수 25점 = 꾸럼e 기록 성실성 + 협업 기여도 + 과정 주도성.
> 매 정각마다 B가 아래 형식으로 한 블록씩 추가하고 꾸럼e에 그대로 붙여넣는다. **누가 했는지 이름 필수.**
> 캡처(화면, 회의 메모, 멘토링 사진)도 같이 올리면 좋다.

## 기록 형식
```
[HH:MM] 단계: 아이디어 / 기획 / 구현 / 멘토링 / 발표준비
- 한 일: (이름) 무엇을 했다 / (이름) 무엇을 했다
- 결정한 것과 이유:
- 문제와 해결:
- 다음 1시간 목표:
```
