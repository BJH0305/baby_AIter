## T15 원문 대조 메모
- 모든 카드는 사람 검수 전 초안이며 확인은 미완료입니다. 24~47개월은 서비스 범위로, 각 이유의 연령별 빈도 근거는 [확인 필요]입니다.
- 인용은 원문 목록 항목·제목·문장 일부를 포함한 연속 발췌(40자 이내)입니다. 인쇄 쪽수와 PDF 페이지를 구분합니다.
- 국내 자료는 우선 사용하되 만 1세 사례(지침서·지도사례), 21개월 사례(자율성)를 24~47개월 전체에 일반화하지 않습니다. 직접적인 깨물기 설명은 보조 자료로 대조했습니다.
- 이사·입소·배고픔·모방은 보조 웹 자료와 함께 확인합니다. 웹 자료에는 임의의 쪽수를 부여하지 않습니다. K-DST 자료·문항은 사용하지 않았습니다.
- 위험 키워드는 이전 안전 규칙을 유지한 검색어 초안입니다. 신호와 부정문을 구별하는 정확성은 사람 검수 필요입니다.
