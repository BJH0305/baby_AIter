## 1. 한 줄 정의
- 서비스 이름: 베이비 AI터 (팀명과 같음. 바뀌면 여기만 고친다)
- 한 줄 소개: 친구·동생을 깨무는 만 2~3세 아이의 부모가, 공공기관 자료에 근거한 연령별 지도법을 받아 일상에서 적용해 보고, 결과에 따라 방법을 조정하도록 돕는 AI 상담 웹
- 디자인 레퍼런스: Mobbin에서 고를 예정 (미정이면 DESIGN.md 기본값)
- 꼭 넣고 싶은 기능: 근거 기반 AI 답변(지도법 여러 개), 적용 결과 피드백 → 맞춤 재답변

## 2. 문제
- 초기 고객: 창원에 사는 30대 맞벌이 부모. 어린이집에 다니는 만 3세 첫째와 돌이 안 된 둘째를 키움
- 장면: 어린이집에서 "오늘 친구를 깨물었다"는 연락을 받고, 집에서는 동생도 깨문다. 맘카페·유튜브를 찾아보지만 방법이 제각각이라 혼내거나 그냥 넘어간다.
- 고객의 문제(키워드): 깨물기 행동 원인 모름(친구·동생) / 동생 질투 대처 / 일관성 없는 훈육 / 믿을 만한 정보 부족 / 맞는 지도법·놀이 모름 / 적용 후 효과 확인 어려움
- 문제정의: 어떻게 하면 부모가 여러 곳에서 정보를 찾아 헤매지 않고, 아이의 특성과 깨무는 상황을 바탕으로 행동의 원인을 근거 자료에 기반하여 빠르게 파악할 수 있을까?
- 근거 숫자 + 출처: [확인 필요]
- 대체재와 한계: 맘카페·육아 커뮤니티, 육아 유튜브, AI 챗봇 → 경험담·일반론이 많고 영상이 길어 우리 아이 상황에 맞는 근거 있는 답을 바로 찾기 어렵다.

## 4. 화면
| 화면 | 사용자가 하는 일 | 결과로 보이는 것 |
| --- | --- | --- |
| 홈 | 아이 프로필(가명, 개월 수) 확인, 진행 중인 상담 보기 | 이번 주 시도한 지도법 수, 최근 기록 |
| 상담하기 | 대상(친구/동생), 상황 칩, 짧은 설명 입력 | AI 분석 요청 |
| 결과 | 원인 해석과 지도법 3개 읽기, "해 볼게요" 선택 | 근거 카드·출처, 단계 표시(가정 지도/관찰 필요/전문가 상담) |
| 기록 | 지도법별 "효과 있음/조금/없음" + 메모 → 다시 상담 | 시도 기록 타임라인, 조정된 2차 답변 |

## 5. 핵심 기능 (우선순위)
1. 근거 검색 + AI 답변: 입력 → 지식 카드 2~3개 검색 → 카드만 근거로 원인·지도법 3개 생성, 출처 표시
2. 적용 결과 피드백 → 재상담: 이전 상황·시도·결과를 함께 보내 조정된 답변
3. 단계 안내: 카드 redFlags·2주 이상 무개선 규칙으로 "전문가 상담 권장" 표시 (안전장치)

## 6. 시연 시나리오 (90초)
1. 홈: 가명 "도윤(38개월)" 프로필, 3일 전 상담 기록이 보인다
2. 상담하기: 대상 "동생", 상황 "엄마가 동생을 안고 있을 때" 선택 → 분석
3. 결과: 원인(관심·질투, 감정 표현 미숙) + 지도법 3개 + 근거 출처 카드
4. 기록: 미리 들어 있는 3일치 피드백("단독 시간은 효과 있음, 즉시 제지는 없음") → 다시 상담 → 조정된 답변(효과 있던 방법 강화, 없던 방법 교체)
