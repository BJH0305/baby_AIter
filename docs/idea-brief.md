# 아이디어 기획서 — 베이비 AI터

> 꾸럼e 최종본(페르소나·문제상황·해결 5p)과 docs/SCOPE.md 기준.

## 1. 서비스
부모가 입력한 연령·깨무는 상황·컨디션을 근거 자료와 매칭해 원인 후보와 출처를 제시한다. 대상 연령 제한은 없다. 연령은 입력 정보로 사용하며 결과는 진단이 아니다.

## 2. 페르소나와 문제
- 창원에 사는 30대 맞벌이 부모. 만 3세 첫째와 돌 안 된 둘째를 키운다.
- 첫째가 어린이집에서 친구를 깨물고 집에서는 동생도 깨문다. 부모는 여러 자료를 찾아보지만 아이 상황에 어떤 이유가 연결되는지 파악하기 어렵다.
- 문제정의: 어떻게 하면 부모가 여러 곳에서 정보를 찾아 헤매지 않고, 아이의 특성과 깨무는 상황을 바탕으로 행동의 원인을 근거 자료에 기반하여 빠르게 파악할 수 있을까?
- 대체재: 맘카페·육아 커뮤니티, 육아 유튜브, AI 챗봇.
- 통계·인터뷰 수치: [확인 필요]

## 3. 화면과 흐름
1. 홈: 가명·개월 수, 검사 시작, 최근 검사.
2. 질문 검사: 첫 안전 확인, 상황·대상·장소·컨디션·이앓이·표현·최근 변화. 기타 직접 입력과 선택 메모.
3. 결과: 안전 안내 최우선, 입력 요약, 가능성이 높은 원인 후보·이유·대응과 근거 출처. fast로 AI 설명 요청, 실패 시 규칙 설명 유지.
4. 기록: 검사 타임라인과 결과가 맞았나요(맞아요/일부/아니에요), 확인 시트로 삭제·전체 초기화.

## 4. 구현 원칙
- 근거에 없는 내용을 지어내지 않고, 미확인 정보는 [확인 필요]로 유지한다.
- 순위는 규칙이 정하며 확률·정확도를 표시하지 않는다. 진단·질환 가능성 표현 금지.
- 카드 ageMonths는 참고용이며 후보 제외에 쓰지 않는다. 연령은 AI 요청 input.ageMonths로 전달한다.
- 친구·형제자매 선택을 점수와 화면 대응 표현에 반영하되 원문 데이터는 보존한다.
- API 키와 모델 선택은 서버에만 둔다. K-DST 문항을 복제하지 않는다.

## 5. 시연
도윤(가명, 38개월), 동생 5개월. 친구와 형제자매를 선택한 결과를 비교하고, 52개월도 후보가 나오는 것을 확인한다. 시연 복원은 홈 제목 5회 탭.

## 6. 팀과 범위
배준희: 구현, 한서희: 유아교육 내용 검수, 이성찬: 디자인·발표. 로그인·결제·진단·아이 사진 기능은 만들지 않는다.
