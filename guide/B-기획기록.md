# B. 기획·기록 플레이북 (기획·수행 50점 책임)

> 목표: 근거 있는 기획서 + 꾸럼e 기록을 1시간마다 빠짐없이.
> 수행 25점은 꾸럼e 기록 성실성·협업 기여도·과정 주도성이다. 꾸준히 쓰기만 해도 확보되는 점수다.

## 왜 이렇게 하나 (점수 전략)
- 기획 25점은 두 최우수상(총장상) 모두에 들어간다. 그중 "전공 융합"과 "사회적 유용성"은 근거가 있어야 점수가 된다
- 근거 숫자 1개 + 실제 사용자 의견 3~5명이 발표 설득력의 절반이다. 없는 숫자는 절대 지어내지 않는다
- 수행 점수는 다른 팀이 가장 많이 놓치는 항목이다. 매 정각 기록만 지켜도 과정상(2팀) 후보가 되고, 총장상 탐구형(기획+수행+발표)도 열린다
- 화면에 들어갈 실제 문구와 데이터는 B가 쓴다. 가짜 예시("홍길동", "테스트")가 AI티의 주범이다

## 꾸럼e란
- PBL(프로젝트 기반 학습)용 **웹 플랫폼**이다. 종이가 아니다.
- OT 자료 기준: 팀별 실습지(아이디어 기획지) 제공, 아이디·비밀번호와 참여코드는 당일 배부, 팀원이 **동시에 작업 가능**.
- git 커밋 기록은 우리 팀 내부 증거이고, 심사위원이 보는 공식 기록은 꾸럼e다. 둘 다 남긴다.

## 오늘 밤
- [ ] 아이디어 후보 2~3개, 각각 **근거 숫자 1개 + 출처**
  - 통계: KOSIS 국가통계포털, 공공데이터포털(data.go.kr), 경상남도·창원시·거제시 통계
  - 뉴스 기사 1개 (날짜와 매체 이름 적기)
- [ ] `docs/idea-brief.md` 양식 한 번 읽기

## 기록 잘 쓰는 법
- "구현함"보다 "OO이 검색 결과가 없을 때 안내 문구를 추가함 (사용자 테스트에서 2명이 헤맴)"처럼 **이유와 근거**를 쓴다
- 결정 기록이 핵심: 무엇을 골랐고, 무엇을 버렸고, 왜
- 문제와 해결: A가 막혔다 풀린 것, 멘토 말 듣고 바꾼 것
- 사진: 회의 화이트보드, 화면 캡처, 멘토링 장면을 같이 올린다
