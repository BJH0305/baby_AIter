# 범위 변경 (10/30 20:14) — 이 문서가 idea-brief보다 우선

## 새 범위
부모가 깨무는 현장을 본 직후, 웹 검색에 시간을 쓰지 않고 **간단한 질문 검사(8문항(안전 확인 포함))로 행동의 원인 후보를 빠르게 파악**하도록 돕는다.

새 문제정의: 어떻게 하면 부모가 여러 곳에서 정보를 찾아 헤매지 않고, 아이의 특성과 깨무는 상황을 바탕으로 행동의 원인을 근거 자료에 기반하여 빠르게 파악할 수 있을까?

## 흐름 (TO-BE)
현장 목격 → 질문 검사(5분 이내 목표) → 원인 후보 2~3개 + 근거 출처 확인 → (선택) "결과가 맞았나요?" 1탭

## 바뀜 / 유지
- 바뀜: 핵심 기능(질문 검사로 원인 후보 안내), 입력 화면(상황 칩 → 질문 8개(안전 확인 포함)), 결과 화면(원인 후보 + 근거 출처 + 진단 아님 문구), 지식 카드(원인 후보 분류), 시연 시나리오
- 유지: 초기고객(창원 30대 맞벌이 부모), 부모만 대상, 공식 자료 근거와 출처 표시, 안전장치(위험 신호 → 전문가 상담 권장), AI 연결(Worker), 디자인 방향

## 원인 후보 분류 (카드 단위)
탐색·이앓이 / 좌절·표현 부족 / 관심 끌기 / 환경 변화·스트레스 / 독립·통제 욕구 / 또래 놀이 학습 / 피로·컨디션

## 지켜야 할 것
1. 거짓 금지: 직접 확인한 자료만. 못 찾으면 "[확인 필요]".
2. 결과는 "가능성이 높은 원인 후보, 진단이 아님". 정확도·% 수치 표시 금지.
3. "5분 이내"는 목표. 팀원이 직접 시간을 잰 기록이 있기 전에는 사실처럼 쓰지 않는다.
4. 질문은 공식 자료의 관찰 항목(직전 상황, 누구를 깨물었나, 장소·시간, 컨디션, 이앓이 시기, 말 표현 수준, 환경 변화)만 바탕으로. **K-DST 문항 복제·인용 금지.**

## 결정 (10/30 21:04 팀 투표 확정)
- 피드백: "결과가 맞았나요?" 1탭(맞아요/일부/아니에요)만 남긴다.
- 연령: 대상 연령 제한 없이 입력값(예: "도윤 · 38개월")으로만 표시한다. 카드 ageMonths는 참고 데이터이며 필터로 사용하지 않는다.
- 대응법: 원인마다 **2~3줄**. 반드시 해당 원인 근거 자료(같은 PDF·쪽)에 있는 내용만 쓰고, 출처 쪽수를 함께 남긴다. 자료에 없으면 줄 수를 줄이고 지어내지 않는다.

## 팀원 피드백 반영
- 안전 확인을 첫 문항으로 분리하여 총 8문항이며 안전 질문 외의 문항에 기타 직접 입력을 제공한다.
- 대상 연령 제한은 없다. 입력 연령·깨무는 상황·컨디션을 근거 자료와 매칭해 원인 후보와 출처를 제시한다. 안전 안내가 항상 먼저다.
- 대체재: 맘카페·육아 커뮤니티, 육아 유튜브, AI 챗봇.

## 꾸럼e 최종본 기준
- 페르소나: 창원에 사는 30대 맞벌이 부모. 만 3세 첫째와 돌 안 된 둘째를 키우며 첫째가 친구와 동생을 깨문다.
- 해결(5p): 부모가 입력한 연령·깨무는 상황·컨디션을 근거 자료와 매칭해 원인 후보와 출처를 제시한다.
- 친구는 frustration +1(보육교사 지침서 p.227~229), 형제자매는 change +2(양육상담 자료집 p.17). 장소는 점수 없이 참고한다.
- 답변 방식 선택 없이 fast 요청. 결과는 입력 요약·안내 두 줄·원인 후보·대응·근거로 구성하며, 예전 형식 기록은 숨긴다.
