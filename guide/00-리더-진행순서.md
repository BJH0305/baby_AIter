## 비상시
| 상황 | 대응 |
| --- | --- |
| Codex 연결이 안 됨 | 운영진에게 바로 문의. 그동안 Claude·ChatGPT 웹 채팅에 `docs/CONTEXT.md`, `AGENTS.md`, `docs/spec.md` 내용을 붙여넣고 파일 단위로 코드를 받아 붙인다 |
| Codex 사용량 제한·느려짐 | 지시를 더 작게 쪼갠다. 한 번에 파일 하나, 기능 하나 |
| 와이파이 끊김 | 휴대폰 핫스팟. 글꼴·아이콘은 인터넷에서 불러오니 시연 전 확인 |
| 노트북 고장 | 마지막 push까지는 GitHub에 있다. 팀원 노트북에서 `git clone` 후 이어서 |
| 팀원이 잘 안 움직임 | 매 정각 체크에서 다음 1시간 목표를 리더가 구체적으로 정해 준다. 협업 기여도가 채점 항목이라 혼자 다 하는 건 손해 |
| 발표 직전 화면이 깨짐 | `git checkout 시연-v1`로 동결 시점으로 되돌리고, 안 되면 바로 영상 시연 |
