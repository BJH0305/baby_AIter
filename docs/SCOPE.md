# 범위 변경 (10/30 20:14) — 이 문서가 idea-brief보다 우선

## 새 범위
부모가 깨무는 현장을 본 직후, 웹 검색에 시간을 쓰지 않고 **간단한 질문 검사(5~7문항)로 행동의 원인 후보를 빠르게 파악**하도록 돕는다.

새 문제정의: "어떻게 하면 부모가 여러 곳에서 정보를 찾아 헤매지 않고, 아이의 특성과 깨무는 상황을 바탕으로 행동의 원인을 빠르고 정확하게 파악할 수 있을까?"

## 흐름 (TO-BE)
현장 목격 → 질문 검사(5분 이내 목표) → 원인 후보 2~3개 + 근거 출처 확인 → (선택) "결과가 맞았나요?" 1탭

## 바뀜 / 유지
- 바뀜: 핵심 기능(지도법 상담 → 질문 검사로 원인 후보 안내), 입력 화면(상황 칩 → 질문 5~7개), 결과 화면(원인 후보 + 근거 출처 + 진단 아님 문구), 지식 카드(원인 후보 분류), 시연 시나리오
- 유지: 초기고객(창원 30대 맞벌이 부모), 부모만 대상, 공식 자료 근거와 출처 표시, 안전장치(위험 신호 → 전문가 상담 권장), AI 연결(Worker), 디자인 방향

## 원인 후보 분류 (카드 단위)
탐색·이앓이 / 좌절·표현 부족 / 관심 끌기 / 환경 변화·스트레스 / 독립·통제 욕구 / 또래 놀이 학습 / 피로·컨디션

## 지켜야 할 것
1. 거짓 금지: 직접 확인한 자료만. 못 찾으면 "[확인 필요]".
2. 결과는 "가능성이 높은 원인 후보, 진단이 아님". 정확도·% 수치 표시 금지.
3. "5분 이내"는 목표. 팀원이 직접 시간을 잰 기록이 있기 전에는 사실처럼 쓰지 않는다.
4. 질문은 공식 자료의 관찰 항목(직전 상황, 누구를 깨물었나, 장소·시간, 컨디션, 이앓이 시기, 말 표현 수준, 환경 변화)만 바탕으로. **K-DST 문항 복제·인용 금지.**

## 결정 (팀장 확정 전 기본값 — 바뀌면 여기만 고친다)
- 피드백: "결과가 맞았나요?" 1탭(맞아요/일부/아니에요)으로 축소
- 연령: 화면 표시는 "만 2~3세", 내부 계산은 개월 수(24~47)
- 대응법: 원인 카드마다 "이럴 땐 이렇게" 한 줄만
